# 迭代 2026-11-02：GameEvents、贸易、病号、存档 v2、UI

本轮为多 agent 并行交付的玩法与界面增量，目标是在既有 64×64 垂直切片上补齐「居民个体 + 经济交换 + 随机扰动 + 可恢复进度」。

## 第四轮演示布局（2026-11-02 晚）

- `_build_demo_town`：增民居/联排/仓库×2/水井×4、码头侧与内城道路网；默认相机 `54,66` / `size 38`（河湖+主聚落构图）。
- `Main._reconcile_assignments`：`wp` 去掉显式类型注解，修复 Godot 4.7 脚本加载失败（否则 `--autotest` 无法启动）。


- 新增 `class_name GameEvents`：`try_daily` 每日最多 1 条；`try_refugees` 春季额外判定难民。
- 事件类型与基准日概率：`fire`（夏/秋更高）、`plague`、`food_shortage`、`cold_snap`、`good_harvest`、`traveling_merchant`、`refugees`。
- `GameState.event_weights` 按 id 倍率；`GameEvents.chance` 叠乘；建成建筑 **&lt;3** 不触发；负面事件有建筑数 / 开局日数衰减（`_negative_risk_mult`）。
- 正面事件（丰收、行商）优先 roll；瘟疫 `_outbreak` 感染 2–4 人；寒潮写入 `GameState.cold_snap_days`（影响 `season_work_mult`）。
- 火灾仍走 `Building.ignite`；水井 `WELL_IGNITE_BLOCK` 可挡火。
- `Main._try_disaster` 改调 `GameEvents`；春季 `_try_refugees` 调 `try_refugees`。
- `--autotest` 关闭 `GameState.random_events_enabled`；`--savetest` 仍可能打印 `[EVENT]`（未关事件，仅 savetest 场景）。

## 贸易（`GameState.gd` + `GameUI.gd` + `Main` 选中面板）

- 常量：`TRADE_INTERVAL=6` 游戏日自动结算；卖出 20 单位富余资源（wood/stone/food/firewood/leather 中选库存最高且 ≥ 阈值）；`TRADE_BUY_RATIO=0.25`（**4:1**）换 `tools` 或 `clothes`（缺哪个买哪个）。
- 需 **贸易站有人值守**（`staffed_trade_post`）；`trade_manual_day` 限制 **每日一次** 手动贸易（`try_manual_trade` / `can_manual_trade`）。
- UI：选中贸易站显示自动倒计时、预览卖/买资源、「手动贸易（4:1）」按钮与 tooltip；日志 `贸易站（手动/自动）：…`。

## 病号与医院（`Citizen.gd` + `GameState` + `GameEvents`）

- 居民：`hunger` / `warmth` / `health` / `sick`；`infect` 头顶 Label3D「病」；病中减工、寻路范围缩短。
- 每日 tick：有 `sick` 时医院值守（`active_hospital`）则 `sick` 减 2、health 减 4，否则减 1 / 减 14；康复清 label。
- 瘟疫事件批量 `infect`；`GameState.sick_count`、日结日志「病号 N 人…」。
- `BuildingDefs` / 经济链：猎人→皮革、裁缝→衣物、铁匠→工具（配合贸易换购）。

## 存档 version 2（`Main.save_game` / `load_game`）

- JSON `version: 2`；字段：`t`、`stock`、`happiness`、`trade_manual_day`；建筑含施工/火灾/工人下标、`lock_workers` / `job_priority`（可选）；居民含 `pos`、`age`、`hunger/warmth/health/sick`、`carry`、`home/work/site` 建筑下标。
- 读档：清空网格与实体 → 恢复 stock/时间/幸福/手动贸易日 → `apply_save_event_fields` → 重建建筑与居民 → `_relocate_citizens_after_load` → `_reconcile_assignments` → `_assign_jobs`。
- **写入含** `cold_snap_days`、`random_events_enabled`、`event_weights`（与 README 存档表一致）。
- `--savetest`：`before`/`after` 快照 `pop/bld/wood/food/fire/day` 一致即通过。

## UI（`GameUI.gd`）

- 顶栏：四季进度文案；人口含「病 N」与半数以上高亮；资源 ⚠ 与冬季/工具/衣物/寒潮 eff 摘要；幸福度分档着色。
- 选中建筑：医院「在治病人」；贸易站贸易行与按钮；建造按钮 tooltip 含造价与禁用原因。
- 有岗位建筑：显示「工人 n/m」、在岗居民编号列表；**优先指派**（`job_priority` + 立即补员）、**锁定工人** toggle（`lock_workers`，自动排班不调离）。
- 操作提示条含 F5/F9。
- **F8** 隐藏小面板：切换 `random_events_enabled`；`event_weights` 各 id 显示倍率，±0.1 写回 `GameState`（0–5  clamp）。默认隐藏，不影响 autotest 启动时关事件。
