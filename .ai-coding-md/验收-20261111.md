# 验收 2026-11-11（居民衰老与生殖）

环境：Godot 4.7.2。自动化命令见 README「测试与截图」。本轮不改画面、着色器或 `--shot` 光照。

## 自动化（必过）

1. `Godot ... --headless --path . -- --autotest` exit 0。末尾 `[8]` 与 README「自测基线」逐字一致（人口=10、木=276、食=402、柴=84）。无 `AUTOPLAY 建造失败`。无脚本加载 / 类型推断错误。
2. `SELFTEST` 含「存档 v2 事件字段: OK」「放置 dock水边find: OK」「牧场经营: OK」「居民生命周期: OK」（`chance` / `birth` / `infant` / `idle` / `work` / `adult` / `elder` / `assign` 均为 true）。
3. `--savetest`：`before` 与 `after` 相同，`events before` 与 `events after` 相同（`pop=9`、`fire=0.35`、`cold=2`）。

## 生命周期（目视）

4. 新建并完工一座有空床的住宅后，若镇上另有房屋住着至少 3 名 16–40 岁居民，会迁入一人组成一对。幸福与食物足够时，日志可出现「一名新生儿降生」；新生儿体型较小，状态为「幼童」，不会被派去工位。
5. 顶栏在有对应人口时显示「幼 / 学 / 老」。选中学堂时，说明仍是学童（已满 4 岁、未满 16 岁）的效率圈。
6. 用调试或读档把一名居民年龄设到未满 4 岁：不能上工。调到满 4 岁：日志「一名幼童到了上工的年纪。」，可被指派且效率按学童计算。调到满 16 岁：日志「一名学童成年了。」
7. 把年龄设到 60 岁以上：状态为「老人」，劳动变慢。设到 70 岁以上：有概率「一名居民年迈去世了。」并计入 `dead_count`、出现墓碑。设到 84 岁：当天必定去世。因饥饿/疾病死亡时文案仍是「一名居民死去了。」

## 存档

8. F5 / F9 后居民 `age`、房屋归属与「幼 / 学 / 老」人数一致。旧档无需新字段，缺 `age` 以外的生命周期键也能读取。
9. 读档后幼童不会被重新派到岗位；成年可生育居民仍住在原来的住宅。

## 回归

10. 牧场屠宰/产羔/越冬、贸易、岗位优先/锁定、医院、学堂开课、F8 事件面板、F5/F9 仍可用。
11. 自测计划不建牧场，`[8]` 变化只来自居民出生与幼童不上工，不来自羊群规则。
