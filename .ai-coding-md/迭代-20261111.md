# 迭代 2026-11-11（居民衰老与生殖）

用户要求先做居民生命周期，并且「新生儿不要当天就能上工」。本轮补上年龄阶段、组成家庭、生育与年迈死亡；仓储搬运和胜负条件仍不动。

## 玩法

- **幼童**（未满 4 岁 / 96 天）不能上工、不能被指派，工作效率为 0。满 4 岁后成为学童（效率 55%，学堂圈内 75%），满 16 岁成年。
- **老人**（60 岁起）劳动效率 ×0.75。70 岁前不会因年迈死亡；70–84 岁每日概率由 0.6% 平方插值升至 8%，满 84 岁必定去世。病亡等其他死因文案不变。
- **组成家庭**：空置或未凑齐一对的住宅，会从仍有至少 3 名 16–40 岁居民的房屋里迁入一人，保证原屋还留一对。新建成的住宅会立刻尝试组成家庭。
- **生育**：幸福度 ≥45、食物 ≥80+人口×2.5、同一住宅有空床且已有两名可生育居民时，每日 38% 概率降生 0 岁幼童。口粮仍按全部人口计算。难民仍按默认成年年龄加入。
- 反馈：角色体型随年龄缩放；角色状态显示幼童/学童/老人；顶栏在人数大于 0 时显示「幼 / 学 / 老」；日志有降生、到了上工年纪、成年、年迈去世。
- 学堂说明改为「学童（已满 4 岁、未满 16 岁）」。存档仍是 v2 的 `age`（游戏日），无新字段。

开局殖民者 16–45 岁，短自测不会滚到年迈死亡；`--autotest` 只跑约 32 天，幼童也还不上工。`[8]` 经济基线随出生变严与幼童不上工而改写，见 README「自测基线」。`SELFTEST` 增加「居民生命周期」，用临时住宅隔离验证生育，不依赖自测结束时镇上是否还有空床。

`GameState._new_day` 里年龄比较写成 `var prev_age: int = int(c.age)`，避免从无类型数组元素推断失败导致脚本无法加载。
